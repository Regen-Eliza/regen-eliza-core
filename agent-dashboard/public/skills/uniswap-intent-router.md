# Regen Eliza: Uniswap Value Settlement
## Description
Integrates the Uniswap API for Agentic Finance. If a user's intent requires a specific token (e.g., cUSD on Celo) but they hold ETH, Eliza autonomously swaps and settles the value before bridging.
