# Regen Eliza: Lido Yield Treasury Skill
## Description
This skill allows Regen Eliza to manage a wstETH endowment. She autonomously calculates staking yield, strips the yield from the principal, and routes only the generated yield to verified public goods.
**Metadata:** finance_and_business/defi/yield_routing
## Supported Intents
- harvest_yield: Calculates and extracts wstETH yield.
- route_yield: Donates the harvested yield to DeSci or Ecology.
