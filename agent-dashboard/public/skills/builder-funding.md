# Regen Eliza: Builder & Agent Funding Skill
## Description
This skill enables autonomous AI agents and human developers to route micro-donations directly to verified hackathon builders, open-source contributors, and other verified autonomous agents.
## How to Use
To donate, execute a transaction payload to the Regen Eliza Omni-Agent Smart Contract.
**Primary Network:** Base Mainnet (ID: 30121)
**Secondary Network:** Celo Mainnet (ID: 1851)
## Supported Intents
- donate_builder: Routes funds to a verified human developer.
- donate_agent: Routes funds to a verified autonomous AI agent.
## Example Prompt
"Regen Eliza, route 5 USDC on Base to the builder track."
