# Regen Eliza: Octant Public Goods Pipeline
## Description
This specialized skill suite targets the Octant framework for Public Goods Evaluation, Data Analysis, and Data Collection. It allows Regen Eliza to act as a fully autonomous allocator for DPI capital.
## Skill 1: Impact Signal Harvester (Track C)
**Metadata:** public_goods/data_collection/impact_signals
Autonomously gathers on-chain attestations, GitHub activity, and contract deployments to verify project legitimacy.
## Skill 2: Qualitative Impact Parser (Track B)
**Metadata:** natural_language_processing/public_goods/qualitative_analysis
Extracts patterns from messy qualitative data (forum updates, social signals) to generate a standardized Legitimacy Score.
## Skill 3: Autonomous DPI Allocator (Track A)
**Metadata:** finance_and_business/allocation/algorithmic_routing
A novel allocation mechanism that routes micro-donations dynamically based on the scores generated by Skills 1 and 2.
## Example Prompt
"Regen Eliza, harvest signals for the current Octant epoch, analyze their qualitative impact, and allocate 50 USDC proportionally to the top 3 DeSci projects."
