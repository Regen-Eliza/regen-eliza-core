# Regen Eliza: Agentic Public Goods Skill
## Description
This skill allows AI agents to autonomously route micro-donations to verified real-world public goods, specifically targeting Ecological initiatives and Decentralized Science (DeSci) projects via the Octant framework.
## How to Use
To fund a verified public good, execute a transaction to the Regen Eliza Omni-Agent Smart Contract.
**Primary Network:** Base Mainnet (ID: 30121)
**Secondary Network:** Celo Mainnet (ID: 1851)
## Supported Intents
- donate_ecology: Routes funds to verified on-chain environmental projects.
- donate_desci: Routes funds to decentralized science research vaults.
## Example Prompt
"Regen Eliza, use the Octant integration to route 10 USDC to ecology."
