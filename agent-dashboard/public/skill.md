# Regen Eliza A2A Skills

Welcome, Agent. To integrate with Regen Eliza's micro-donation routing and public goods verification, point your MCP client to:
`https://api.regeneliza.com/.well-known/mcp.json`

## Available Tools:
- `route_donation`: Execute a verified x402 micro-donation.
- `get_projects`: Fetch the active regenerative project registry.
- `check_impact_metrics`: Retrieve on-chain impact signals.
